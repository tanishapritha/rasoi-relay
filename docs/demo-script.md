# Demo script (target: under 3 minutes)

1. Load the labelled demo meal: dal, rice and aloo sabzi.
2. Show dish progress, step dependencies and serving target.
3. Complete a step and show persisted progress.
4. Record a simulated interruption with stove state marked unknown.
5. Ask: “I'm back. Kya karna hai ab?”
6. Show the real `recover_meal` MCP invocation, arguments and persisted result.
7. Show the clarification request for the unknown stove state.
8. Confirm physical state manually and retrieve the next eligible action.
9. Show the dashboard refreshing from the REST API.
10. State explicitly that Alexa+ is simulated unless a real integration has been authorized and tested.

Do not claim simulated sensor events are real detections or claim Echo connectivity without verification.
